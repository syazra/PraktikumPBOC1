# Praktikum PBO C1

Repository ini berisi kumpulan source code praktikum mata kuliah Pemrograman Berorientasi Objek (PBO) menggunakan bahasa Java.

---

# Teknologi yang Digunakan

* Java
* MySQL
* NetBeans IDE

---

# Deskripsi Pertemuan

## Pertemuan 1 - Pengenalan Java

Membahas:

* Struktur program Java
* Class dan object
* Atribut dan method
* Konstruktor, Selektor, dan mutator
* Proses compile dan run program Java

---

## Pertemuan 2 — Class dan Object

Membahas:

* Access modifier
* Encapsulation

---

## Pertemuan 3 — Relasi Antar Objek

Membahas:

* Association
* Aggregation
* Composition

Implementasi relasi antar class dalam pemrograman berorientasi objek.

---

## Pertemuan 4 — Inheritance

Membahas:

* Pewarisan class (`extends`)
* Method overriding
* Keyword `super`

Implementasi inheritance untuk membuat program lebih reusable.

---

## Pertemuan 5 — Abstract Class dan Interface

Membahas:

* Abstract class
* Abstract method
* Interface

Implementasi abstraction pada Java untuk membuat program lebih fleksibel dan modular.

---

## Pertemuan 6 — Asersi dan Eksepsi

Membahas:

* `assert`
* `try-catch`
* `throw`
* `throws`
* Exception handling

Penanganan error pada program Java.

---

## Pertemuan 7 — Polimorfisme

Membahas:

* Polimorfisme ad hoc coercion
* Polimorfisme ad hoc overloading
* Polimorfisme universal inclusion

Implementasi polymorphism dalam Java.

---

## Pertemuan 8 — Generik

Membahas:

* Generik class
* Generik larik
* Generik operator

Implementasi generik untuk membuat kode lebih fleksibel.

---

## Pertemuan 9 — Koleksi

Membahas:

* List
* Queue

Pengelolaan data menggunakan struktur koleksi pada Java.

---

## Pertemuan 10 — Persistensi

Membahas:

* Data Access Object (DAO)
* Koneksi database MySQL
* JDBC
* Operasi CRUD database

Implementasi persistensi objek menggunakan basis data relasional.

---

## Pertemuan 11 — Modularisasi

Membahas:

* GUI Java Swing
* JFrame
* JButton
* JTextField
* JList
* Collection (`List`, `Set`, `Map`)
* JDBC Mahasiswa

Implementasi GUI sebagai antarmuka grafis dalam pemrograman berorientasi objek.

---

## Pertemuan 12 — Lambda

Membahas:

* Lambda inline
* Lambda block statement

Implementasi lambda untuk membuat kode Java lebih ringkas dan modern.

---

# Tujuan Repository

Repository ini dibuat sebagai dokumentasi dan latihan praktikum mata kuliah Pemrograman Berorientasi Objek (PBO), sekaligus sebagai media pembelajaran implementasi Java dari dasar hingga database dan GUI.
