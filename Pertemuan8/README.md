# Praktikum Generic Java

## Deskripsi
Praktikum ini membahas implementasi Generic Programming pada Java, meliputi:

- Generic pada class
- Generic pada operator/method
- Generic pada array/larik

Studi kasus menggunakan keluarga kelas Anabul seperti Kucing, Anjing, Burung, Anggora, dan KembangTelon.

---

## Folder Structure

The workspace contains two folders by default, where:

- `src` : folder untuk menyimpan source code Java
- `lib` : folder untuk dependency/library tambahan

Compiled output akan otomatis masuk ke folder:

- `bin`

Contoh struktur folder:

```text
project-folder
├── src
│   ├── Main.java
│   ├── Anabul.java
│   ├── Kucing.java
│   ├── Anggora.java
│   ├── KembangTelon.java
│   ├── Datum.java
│   ├── OperatorGenerik.java
│   └── Data.java
├── lib
└── bin
